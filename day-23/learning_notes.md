# Day 23 learning notes

Conversion is a ratio between adjacent funnel stages. CAC is spend per new
customer. MRR is recurring revenue per month and ARR is an annualized run rate,
not a promise of realized yearly revenue. LTV depends heavily on its lifetime
and revenue assumptions.

The code returns `None` when a denominator is zero or a required value is
missing. Pipeline velocity is expressed in USD per day from opportunity value,
win rate, and average sales-cycle days. The sample is synthetic and should be
used only to demonstrate formulas.
