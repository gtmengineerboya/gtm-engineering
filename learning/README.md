# learning/

Skill maps built from your own projects, plus practice material.

| File | What it gives you |
|---|---|
| `python-skills.md` | Python skills sorted as Learned, Daily, Strengthen, Add, with 12 drills and a score tracker |
| `sql-skills.md` | SQL skills sorted the same way, with 11 questions and a score tracker |
| `sql-practice/` | Runnable SQL practice data, answer key and a runner |

Start with `sql-skills.md` section 5 (about 90 minutes), then Python drill D1.
Re-score the trackers every two weeks and commit the changes, so you can see the
progress.
