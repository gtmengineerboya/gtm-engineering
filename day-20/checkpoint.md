# Day 20 checkpoint

1. **Does PASS mean the message is good?** No. It means only that these narrow
   deterministic checks found no issue.
2. **What happens to unsupported claims?** They add a reason and require review.
3. **Can this script send a message?** No; it only writes a local review file.
4. **What are model ratings?** Optional subjective judgments kept separate
   from deterministic checks; they cannot approve a message.
